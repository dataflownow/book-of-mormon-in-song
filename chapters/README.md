# Chapter tracker

The goal is complete coverage of the book. Start with a small pilot and expand as the process improves.

Search [existing issues](https://github.com/dataflownow/book-of-mormon-in-song/issues) before claiming a chapter. Any chapter can be proposed using the [claim form](https://github.com/dataflownow/book-of-mormon-in-song/issues/new?template=01-chapter.md). The issue is the current working record; maintainers update this index at milestones.

## Movement records

Use [record-template.md](record-template.md) for verse ranges, versions, credits, production details, reviews, and rights. Review the combined chapter as well as individual movements.

Suggested record path: `chapters/mosiah/02/record.md`. Suggested audio name: `mosiah-02-v017-019-v01.mp3`. Document sentence boundaries when splitting within a verse.

After review, identify one main collection version and link alternate interpretations. Keep review findings tied to the exact audio version.
